# הנחיית עבודה ל-Claude Code — MVP

אתה מפתח לומדת onboarding בעברית למכבידנט בשם "בידיים טובות". קרא קודם את כל מסמכי `good_hands_spec/`. מקור העובדות הוא `01-content-master.md`. תרחישים ותסריטים המסומנים טיוטה אינם מדיניות ארגונית מאושרת.

## תוצאה נדרשת
אפליקציית React + TypeScript + Vite, RTL מלאה, רספונסיבית, נגישה, בעלת חוויית למידה רציפה בישיבה אחת. Tailwind מותר. השתמש ב-state machine או במודל ניווט מפורש, לא בהסתמכות על אינדקס שקופית בלבד.

## שלב 1 — שלד ותשתית
1. הגדר מודל תוכן מבוסס נתונים עם types ו-schema validation למסכים, אפשרויות, משובים, מדיה ומסלולים.
2. מימש ליבה משותפת ומסלולי reception, assistant, clinician (עם יכולת פיצול hygienist בהמשך).
3. מימש נגן קריינות: play/pause, mute, captions/transcript, שינוי מהירות אופציונלי, replay, ביטול אודיו במעבר מסך, מניעת חפיפה בין קטעים.
4. מימש תרחישים עם 3 אפשרויות ומשוב לפי בחירה; תרגול חוזר.
5. מימש מבחן מסכם, ציון, סף מעבר בר-הגדרה, ניסיונות חוזרים וסיכום אישי.
6. שמור התקדמות ב-localStorage לצורכי MVP בלבד; אל תטען שזה מעקב ארגוני מאומת.
7. מימש AnalyticsAdapter עם Noop/Console adapter והאירועים מתוך `05-analytics.md`.
8. הוסף placeholders לכל נכס מדיה חסר, עם manifest; לעולם אל תציג broken images.

## שלב 2 — תוכן
בנה מסכי S00–S09 לפי `02-learning-design.md`. השתמש בתוכן מתוך `01-content-master.md`. אפשר להשתמש בדוגמאות `03-scenario-bank.md` בסטטוס DRAFT בגרסת פיתוח בלבד; הצג ב-dev mode סימון "טעון אישור". אל תמציא נוהל רפואי, התחייבות זמן, מידע תשלום או כללי פרטיות.

## שלב 3 — בדיקות
- בדיקות יחידה לחישוב ציון, מסלולים, שמירת התקדמות, מניעת דילוג לא רצוי והפעלת אנליטיקס.
- בדיקות E2E למסלול עובד חדש, חזרה למסך, refresh, כישלון ומבחן חוזר, אודיו חסר, רשת איטית.
- RTL, מקלדת, focus, קורא מסך, ניגודיות, reduced motion, כתוביות, 360px mobile ו-desktop.
- מדידת זמן השלמה אמיתי בפיילוט ולא לפי אומדן בלבד.

## קריטריוני קבלה
- עובד יכול לסיים מסלול אחד מתחילתו ועד סופו בישיבה אחת.
- בחירת תפקיד משנה את התרחישים הרלוונטיים בלי לפגוע בליבה המשותפת.
- שום אודיו לא מתנגן אוטומטית לפני אינטראקציה.
- אפשר להשלים את הלומדה גם בלי אודיו, באמצעות תמלול.
- כל בחירה נרשמת באירוע תקין, גם כשאין שירות אנליטיקס חיצוני.
- לא נאסף מידע אישי או רפואי.
- כל התוכן ניתן לעריכה מחוץ לקומפוננטות.

## שיטת עבודה
ראשית הצג תוכנית עבודה, tree, types ומסכי wireframe טקסטואליים. בנה vertical slice עובד: פתיחה → ערך → תרחיש → משוב → סיכום. בדוק אותו, ורק אז הרחב לכל המסכים. אל תפיק תמונות/קריינות כתחליף לתוכן שטרם אושר.
