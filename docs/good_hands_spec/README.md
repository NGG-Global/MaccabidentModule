# בידיים טובות — חבילת אפיון ל-Claude Code

גרסה 0.1 | טיוטה לאישור מקצועי | מקור: מצגת מכבידנט, 31 עמודים.

## החלטות מאושרות מצד המזמין
- לומדה אחת בישיבה אחת, יעד 25–35 דקות.
- ליבה משותפת ומסלולים ייעודיים: נציגות שירות, סייעות, רופאי/ות שיניים ושינניות.
- תמונות, אנימציות וסרטוני AI קצרים.
- קריינות מלאה באמצעות ElevenLabs, כולל משובים, עם אפשרות להשתיק/לקרוא.
- הערכה מסכמת עם ציון ותרגול חוזר.
- תכנון מראש לאנליטיקס, ללא תלות בספק מסוים.

## סדר עבודה
1. לעבור על `01-content-master.md` ולאשר עובדות, נוסחים וחריגות.
2. לאשר מטרות, מסכים ותנאי מעבר ב-`02-learning-design.md`.
3. לאשר תרחישים ודיאלוגים ב-`03-scenario-bank.md`.
4. להכין טקסטי קריינות ומדיה לפי `04-media-production.md`.
5. לפתח MVP לפי `06-claude-code-brief.md`, עם סכמת האירועים `05-analytics.md`.
6. לבדוק עם עובד חדש ונציג מקצועי מכל תפקיד לפני פריסה.

## גבולות המקור
התנהגויות וערכים מקורם במצגת. דמויות, סיטואציות, תשובות ומשובים הם **תוכן חדש מוצע**, לא ציטוטים מהמצגת. פרוצדורות רפואיות, הבטחות זמן, תשלום ופרטיות מחייבות אישור מכבידנט. סרטוני המצגת אינם כלולים בקובץ PDF כקובצי וידאו שמישים בהכרח.
